# 村庄成长商店

目标版本：Minecraft Java 26.1.2（数据包格式 101.1）。专用服务器需要 Java 25。

## 功能概览

- 玩家进入自然村庄后，会在附近地表生成一座 9×9 商店屋；160 格内只生成一座。
- 房内商人是个人商店入口：右键后会打开原版数据包对话框。分类、商品、任务、教程和设置均以原版物品图标显示，不会连续向聊天栏输出菜单。
- 管理员可以向指定玩家发放绑定的“便携商店钥匙”；持有者右键钥匙即可在任意地点打开自己的商店。钥匙被转交不会转移权限。
- 主线、困难终局和儿童守护线均使用个人进度，多人互不共享阶段；黑市制裁等级全局共享。
- 普通目标只有在本人兑换任务道具、任务正式激活后才计数。
- 晋级必须同时完成普通目标并持有本人登记的正确任务道具；提交会消耗任务道具。
- 任务道具与辅助用品拥有不同 `custom_data` 身份，不能互相替代。
- 当前任务道具丢失后可免费补领一次；辅助用品永久登记，可在丢失后补领。
- 已解锁资源和消耗品不会回退；旧装备回溯只切换装备查看页，再由玩家确认兑换。
- 商人可被击杀或移除，约 5 秒后补回，并提高全局黑市制裁等级。

## 安装与打开商店

把本目录复制到：

`存档目录/datapacks/村庄32K商人/`

进入世界后执行 `/reload`。出现绿色加载提示后进入自然村庄，右键房内的“成长商店”商人。

商店分为：

- 当前装备
- 已解锁资源
- 已解锁消耗品
- 必需任务道具
- 可选辅助用品
- 当前任务与提交
- 委托、难度和旧装备回溯

关闭对话框后，可在商人 6 格内执行 `/trigger vt_menu set 1` 重新打开。已登记且随身持有便携钥匙时也可使用该命令。所有购买和提交都会再次校验距离、阶段、所有权与材料，不能通过伪造 trigger 绕过。

管理员以目标玩家身份执行以下命令即可发放或补发钥匙；补发会替换该玩家现有的本包钥匙，不会重置主线、儿童线、任务牌或制裁数据：

```mcfunction
execute as <玩家> run function village_trader:portable/grant
```

钥匙是不可堆叠物品。领取者权限登记在玩家数据中：未登记玩家即使拿到他人的钥匙，右键也只会收到未授权提示；登记玩家丢失钥匙后，需要管理员补发。

## 主线成长

| 当前阶段 | 激活后的普通目标 | 必需任务道具 | 晋级解锁 |
|---|---|---|---|
| 1 | 挖 8 个钻石矿、击杀 20 只敌对生物 | 矿工试炼证：16 铁锭 + 8 煤炭 | 5 级钻石装备、钻石、绿宝石、金苹果 |
| 2 | 进入下界、击杀 10 烈焰人、挖 4 远古残骸 | 下界通行证：8 黑曜石 + 打火石 + 4 金锭 | 10 级下界合金装备、钻石块、绿宝石块、下界合金碎片 |
| 3 | 进入末地并击杀末影龙 | 末地追踪证：12 末影珍珠 + 12 烈焰粉 | 20 级传说装备、下界合金锭、附魔金苹果 |
| 4 | 亲自赢得袭击，并在任务激活后亲自拾取图腾 | 村庄守卫令：16 绿宝石 + 1 不祥之瓶 | 32 级神话装备、不死图腾 |
| 5 | 击杀凋灵并制作信标 | 凋灵挑战书：4 灵魂沙 + 8 黑曜石 + 1 附魔金苹果 | 64 级普通终焉装备、下界合金块、全部普通商品 |
| 普通 6 → 困难终局 | 击杀监守者 | 深暗挑战书：8 回响碎片 + 1 幽匿催发体 + 1 图腾 | 255 级 32K 装备与困难终局能力 |

挖掘、击杀、维度、袭击和制作均使用个人事件或统计基线；任务激活前的历史行为不会直接完成当前任务。商店 `/give` 的资源不会增加挖掘或拾取统计。

困难模式在普通第六阶段开放。深暗挑战完成前，困难当前装备按第五阶显示；资源和消耗品不会回退。困难终局套装效果同时校验个人阶段、困难模式和本人完成记录，转交装备不能解锁能力。

## 主线辅助用品

- 矿工补给包：火把、食物和短时急迫。
- 下界护符：在下界提供防火与抗性。
- 末地护符：在末地提供缓降与恢复。
- 袭击守护符：只在附近存在带 `RaidId` 的实际袭击成员时生效。
- 凋灵净化符：提供抗性并清除凋零。
- 幽匿护符：在深暗之域提供速度、抗性与恢复。

同一时间只启用当前选择的一件主线辅助用品；必须拥有登记并随身携带正确物品。

## 黑市制裁

普通商品与装备使用当前总价：

- 0 级：1 泥土
- 1 级：16 泥土
- 2 级：16 绿宝石
- 3 级：4 下界合金锭

任务道具和主线辅助用品保留其列明材料成本；制裁 1–3 级会额外收取对应附加费。所有材料先完整检查，再一次性扣除，不会出现扣到一半失败。

管理命令：

- `/function village_trader:penalty/normal`
- `/function village_trader:penalty/mild`
- `/function village_trader:penalty/severe`
- `/function village_trader:penalty/extreme`

## 儿童守护线

管理员以目标玩家身份执行：

```mcfunction
execute as <玩家> run function village_trader:child/enable
execute as <玩家> run function village_trader:child/disable
execute as <玩家> run function village_trader:child/reset
execute as <玩家> run function village_trader:child/status
```

- `enable`：启用儿童商店并保留既有儿童进度。
- `disable`：暂停儿童线，保留进度并恢复主线商店。
- `reset`：只重置儿童六章、Boss、印记、辅助用品和升格记录，不修改主线。
- 儿童普通商品固定 4 泥土；选中并携带商人徽章后为 1 泥土，不受全局制裁影响。
- 检测到正在生效的主线装备时，儿童线会自动暂停，防止 255/32767 属性绕过儿童安全上限。

六章依次为木工启程、小小矿工、安全过夜、勇气训练、商人助手和守护毕业。每章只显示当前目标并提供带物品图标的对话框教程；圆石、钻石矿和烧制铁锭使用个人统计/熔炼事件，暂停儿童线期间不会继续累计。

木工启程激活后，背包再次持有至少 4 个任意原木即可完成原木目标；背包持有工作台或激活后新制作工作台，均可完成工作台目标。任务页面会分别显示原木、工作台和任务牌状态，提交失败也会明确指出缺少的一项。

儿童辅助用品与 Boss 辅助品共用一个选择槽，始终只启用一件。核心六章毕业后依次开放末影龙、凋灵和监守者番外；挑战书必须先购买并提交消耗，之后击杀才记录印记。三个印记完成后可兑换并提交守护升格核心，解锁 128 级守护装备和 60 秒冷却的危险生命急救。

## 儿童夜视 API

以下函数均以目标玩家为执行者：

```text
village_trader:api/night_vision/pause_3s
village_trader:api/night_vision/pause_10s
village_trader:api/night_vision/suspend_safe
village_trader:api/night_vision/suspend
village_trader:api/night_vision/resume
village_trader:api/night_vision/refresh
village_trader:api/night_vision/status
```

儿童线正常运行时每秒续期 4 秒隐藏粒子的夜视。`suspend_safe` 只停止续期，让当前效果自然过期；`suspend` 会主动清除当前夜视。

## 其他管理命令

- 手动在当前位置东侧附近建房：`/function village_trader:create`
- 在当前执行位置补一个商人：`/function village_trader:spawn_merchant`
- 清理商人、锚点、调度、个人进度和计分板：`/function village_trader:uninstall`

卸载不会拆除已经生成的房屋方块，避免误删玩家后来放入的物品。

## 测试说明

- 升级旧存档后，确认个人阶段、任务牌、辅助用品和制裁等级不变，且只清除旧聊天菜单的临时状态。旧聊天记录不能由原版数据包删除；如需清空可按 `F3+D`。
- 在单人和双人世界分别验证：右键商人、本人钥匙、未授权玩家、转交钥匙与管理员补发；不同玩家的页面和进度必须独立。
- 覆盖主线与儿童线的分类切换、阶段锁定、动态价格、材料不足、购买、补领和任务提交；日常结果应显示在动作栏。
- 儿童第一章分别测试“激活后持有工作台”与“激活后新制作工作台”，并确认缺原木、工作台或任务牌时均出现准确提示。
- 仍需在可丢弃世界中由真人完成各阶段事件、装备效果和完整 Boss 流程测试。
