# 村庄 32K 矿物商人

目标版本：Minecraft Java 1.21.5（数据包格式 71）。

## 功能

- 玩家第一次进入一个自然村庄时，会在玩家东侧约 14 格的地表生成一座 9×9 特殊交易屋。
- 每个相距 160 格以上的村庄会各自生成一座；普通原版村庄通常满足这个距离。
- 房内商人拥有 `NoAI`，不能走动，但可以被玩家击杀；约 5 秒后会自动补回。
- 只出售钻石、绿宝石、下界合金及其资源块；不出售任何可采掘矿石或普通矿物。
- 所有神器默认均为 1 个泥土换 1 件，带现代版本允许的 255 级极限附魔、32767 点核心属性、不可损坏和附魔光效。
- 每次商人被击杀或移除都会提高全局黑市制裁等级：先涨至 16 个泥土，再改为 16 个绿宝石，最后改为 4 个下界合金锭；三级后不再继续加重。

## 安装

把整个“数据包”文件夹复制到：

`存档目录/datapacks/村庄32K商人/`

进入世界后执行 `/reload`。出现绿色“数据包已加载”提示即安装成功。随后走进一个尚未生成商店的自然村庄。

专用服务器请使用与 Minecraft Java 1.21.5 兼容的 Java 运行环境。

## 管理命令

- 手动在当前位置附近建房：`/function village_trader:create`
- 只补一个商人（需在屋内锚点处执行）：`/function village_trader:spawn_merchant`
- 清理全部商人、锚点和定时任务：`/function village_trader:uninstall`
- 调整黑市制裁（会立即重设所有商人的交易）：
  - 解除制裁，恢复 1 个泥土：`/function village_trader:penalty/normal`
  - 一级，16 个泥土：`/function village_trader:penalty/mild`
  - 二级，16 个绿宝石：`/function village_trader:penalty/severe`
  - 三级，4 个下界合金锭：`/function village_trader:penalty/extreme`

卸载函数不会自动拆除房屋方块，避免误删玩家后来放进房屋的物品。

## 注意

- 数据包使用运行时检测，因此已生成的旧村庄也能获得商店；房屋不是原版拼图结构的一部分。
- 建房会清理 9×7×9 的空间。建议第一次触发时站在村庄较空旷的位置，玩家东侧不要有重要建筑。
- 两个中心相距不足 160 格的村庄会被当作同一个村庄，以避免同一大型村庄重复刷房。
- Java 26.1.2 把附魔组件等级硬性限制在 0–255，因此本包采用 255 级极限附魔，并用 32767 点攻击、护甲或生命属性保留“32K 装备”的强度。游戏仍会对部分属性的最终生效值作内部钳制。
