# SAN 恐怖幻觉

适用版本：Minecraft Java 26.1.2（数据包格式 101.1）。这是一个独立数据包，命名空间为 `horror_san`，不需要也不会修改村庄商人数据包。

## 安装与开始

1. 将整个 `horror_san` 文件夹复制到存档的 `datapacks/` 目录。
2. 进入该世界后执行 `/reload`。
3. 单人在线时，世界首次进入夜晚会自动选定这名玩家并开始体验；屏幕顶部会显示 0–100 的 SAN 条。

也可以随时执行：

- `/function horror_san:enable`：立即开始或重新开始一次体验。
- `/function horror_san:disable`：立即隐藏 SAN 条、停止事件并清除当前幻象；之后需执行 `enable` 才会再次开始。
- `/function horror_san:uninstall`：执行同样的清理并保持停用状态。计分板会保留，因为 tick 函数仍会引用它们。

## 体验说明

- 本包按一次一名体验者设计。多人服务器请只让一名玩家在线或参与。
- 夜晚、低照度（≤7）和雷暴会降低 SAN；明亮白天会恢复 SAN；完整睡过一次夜会恢复 20 点。
- SAN 条依次使用绿、黄、红、紫表示不同风险档位。低 SAN 时可能出现原创文字、原版环境声、短暂黑暗/反胃/缓慢、无伤害幻象及极低概率的快捷栏物品交换。
- 幻象只使用原版实体，40 tick 后自动清除；不会造成伤害、爆炸、方块破坏或掉落。快捷栏事件只会交换两个非空快捷栏格，并先以 storage 备份完整物品数据；不会修改主背包、护甲、副手、末影箱或潜影盒内部内容。

## 提示与手动验证

本包包含低音量原版异响与短暂视觉效果（黑暗、反胃、缓慢）；对闪烁、突发音效或恐怖内容敏感时，请先执行 `disable`。

建议在一次性世界中验证：白天不自动启动；`/time set midnight` 后首次启动且 SAN 条同步；将体验者的 `horror_san.san` 分别设为 70、40、20 以观察分档事件；检查三类幻象在 40 tick 后消失；在 SAN 20 以下确认快捷栏物品及其组件完整；最后运行 `disable` 和 `uninstall`，确认没有新的事件。
